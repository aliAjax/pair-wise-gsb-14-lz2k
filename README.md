# 调价毛利影响双签台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原"油品价格维护"最小闭环上扩展为调价毛利测算 + 双签审批台，数据保存在浏览器 localStorage（key：`dfwlfront-9-price-adjust-v1`），刷新/重载后测算单、预算占用、油价表与版本链保持一致。

## 业务规则

1. **新建测算单**：选择油站、油品、当前价、目标价、预计日销量、单位成本。
2. **毛利测算**：按销量估算调价后首日毛利变化 `(目标价 - 当前价) × 预计日销量`，同时计算单位毛利变化与预算预占（毛利减少额正值）。
3. **两条红线**：
   - 目标价低于单位成本（成本保护线）；
   - 本单预占叠加同油站其他待签单后，超过该油站日毛利减少预算。
   命中任一红线时**必须填写调价依据**，否则送签受阻。
4. **待签互斥**：同一油站同一油品只保留一张待签单；后单提交时受阻并写明油站、油品、差额及命中条件，可一键"撤回前单并释放占位"后自动重提。
5. **逐级签署**：站长先签 → 区域经理后签。双签完成后冻结测算数值、目标价与签名；目标价写入油价表。
6. **更正版本**：已签署单不可改，"更正"另立版本（V2、V3…），版本链保留全部旧数，新版本仍走完整双签。
7. **撤回**：待签单撤回后释放同油站同油品占位与预算预占，撤回原因留痕。
8. **受阻提示**：所有拦截信息明确给出油站、油品、差额及命中条件（成本线差额单位为元/升，预算差额单位为元/日）。
