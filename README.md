# 调价毛利影响双签台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能闭环

1. **新建测算单**：选择油站、油品、当前价、目标价、预计日销量、单位成本，表单实时按
   `(售价 − 单位成本) × 预计日销量` 估算当前/目标首日毛利及调价后首日毛利变化。
2. **双守卫**：
   - 目标价低于成本保护线（保护线 = 单位成本 + 保护加价）→ 命中成本保护，记录每升差额；
   - 毛利减少额超过油站剩余日预算（预算被其他待签单按减少额占用）→ 命中预算，记录差额。
   - 命中任一守卫时**必须填写调价依据**，否则提交被阻断并写入受阻记录。
3. **逐级双签**：站长签署 → 区域经理签署；未完成站长签区域经理不能签。
4. **占位唯一**：同一油站同一油品只能保留一张待签单；新建时若已有待签单，可直接
   「撤回前单并释放占位」，预算占用随之释放。
5. **冻结与版本链**：双签完成即冻结测算、目标价与签名，并把目标价写入当前价；
   后续更正只能「另立版本」，旧版本数据保留并标注「已被更正」，版本链可展开查看。
6. **持久化**：测算单、预算占用、当前价、版本链、受阻记录全部存 localStorage，
   重载后仍对应（storageKey：`dfwlfront-9-dual-sign-desk`）。
7. **受阻记录**：所有阻断均写明油站、油品、差额及命中条件（占位冲突、守卫缺依据、
   越级签署、冻结单撤回等）。
